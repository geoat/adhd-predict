# Repository guidance

Before changing this repository:

1. Read the relevant documentation under `arch/`.
2. For frontend and backend action work, read `arch/best-practices/next-server-actions.md`.
3. Preserve the existing Next.js and Cloudflare Worker deployment architecture.
4. Validate changes with the relevant lint, build, and preview commands.
5. Keep unrelated files and branches unchanged.

The connected GitHub repository is `geoat/adhd-predict`. The primary development branch is `develop`.
